EDUCACRUZ — SITIO WEB INICIAL
=============================

1. VISTA PREVIA
Abre index.html en tu navegador para revisar el sitio en tu computador.
Algunas funciones que cargan archivos JSON pueden no funcionar al abrirlo directamente como archivo local.
Para probarlo correctamente puedes publicarlo en GitHub Pages o usar una extensión de servidor local.

2. ESTRUCTURA
- index.html: contenido y secciones de la página.
- styles.css: colores, diseño y adaptación a móviles.
- script.js: menú y buscador de la biblioteca.
- assets/: logotipo e imágenes.
- materiales/: aquí guardarás los PDF descargables.
- materiales/materiales.json: catálogo de materiales que se muestra en la biblioteca.

3. CÓMO AÑADIR UN PDF
a) Copia el PDF dentro de la carpeta materiales/.
b) Abre materiales/materiales.json con un editor de texto.
c) Añade un objeto siguiendo este ejemplo:
   {
     "titulo": "Taller de lectura - Grado 4",
     "area": "Lengua Castellana",
     "grado": "Grado 4",
     "descripcion": "Actividad de comprensión lectora.",
     "archivo": "taller-lectura-grado-4.pdf"
   }
d) Guarda el archivo. El nombre en "archivo" debe coincidir exactamente con el PDF.
e) Sube los cambios a GitHub. GitHub Pages actualizará el sitio automáticamente.

Áreas disponibles en el filtro:
Lengua Castellana, Matemáticas, Inglés y General.

4. CÓMO PUBLICAR GRATIS CON GITHUB PAGES
a) Crea una cuenta en https://github.com/
b) Verifica tu correo.
c) Crea un repositorio nuevo y público. Puedes llamarlo educacruz.
d) Sube el CONTENIDO de esta carpeta (no el ZIP) al repositorio.
e) En el repositorio entra en Settings > Pages.
f) En "Build and deployment", selecciona "Deploy from a branch".
g) Elige la rama "main" y la carpeta "/ (root)"; pulsa Save.
h) Espera a que GitHub Pages publique el sitio. La dirección aparecerá en esa misma sección.

5. CÓMO ACTUALIZAR
Cada vez que edites textos, imágenes, CSS o añadas PDF, guarda los cambios y súbelos al repositorio de GitHub. La publicación se actualizará automáticamente después del proceso de despliegue.
